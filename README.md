# 🍽️ Recipe List Frontend

A React.js frontend for the Recipe Management System that allows users to view, search, add, edit, and delete recipes through a clean and responsive interface.

## 🚀 Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Axios

## 📋 Prerequisites

- Node.js (v18 or above)
- npm

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/SUDHARSAN-gitpro/RecipeList-frontend.git
```

### Navigate to the project

```bash
cd RecipeList-frontend
```

### Install dependencies

```bash
npm install
```

### Start the application

```bash
npm start
```

or (if using Vite)

```bash
npm run dev
```

The application will run at:

```
http://localhost:3000
```

or

```
http://localhost:5173
```

## ✨ Features

- View recipes
- Add new recipes
- Edit recipes
- Delete recipes
- Search recipes
- Responsive UI

## 📌 Note

This frontend communicates with the ASP.NET Core Web API backend. Make sure the backend server is running before starting the frontend.
